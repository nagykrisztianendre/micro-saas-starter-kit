# Demo data

After `pnpm prisma:seed`, you can log in with:

- Admin: `admin@example.com` / `admin12345`
- User: `user@example.com` / `user12345`

Seeded records:
- plans: `free`, `pro`
- one active `pro` subscription for `user@example.com`

Recommended first demo flows:
1. Log in as user, review Dashboard + Billing status.
2. Log in as admin, review users and subscriptions in Admin.
3. Visit API Keys, Organizations, and Audit Logs placeholder pages to preview extension points.
