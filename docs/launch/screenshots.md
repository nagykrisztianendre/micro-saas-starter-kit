# Screenshot Checklist for Product Launch

Use this checklist to prepare product page and Gumroad visuals.

## Capture guidelines
- Use consistent browser width (1440px recommended).
- Use seeded demo data with realistic names.
- Avoid showing secrets, real API keys, or personal emails.
- Prefer clean UI state with meaningful data (not empty screens).

## Required screenshots

1. **Dashboard overview**
   - Demonstrates: product value at a glance, key metrics/cards, app polish.
2. **Organization management**
   - Demonstrates: multi-tenant readiness and account structure.
3. **Member invitation flow**
   - Demonstrates: team collaboration capability.
4. **API key management**
   - Demonstrates: developer/platform use cases.
5. **Audit log viewer**
   - Demonstrates: traceability and operational visibility.
6. **Admin panel**
   - Demonstrates: operational controls for support/internal teams.
7. **Feature overview panel/page**
   - Demonstrates: breadth of included capabilities.
8. **Project structure (code/editor view)**
   - Demonstrates: clean module organization and developer ergonomics.

## Optional screenshots
- Billing/subscription state UI
- Auth screens (login/register)
- Settings/profile customization page
