# Testimonial Capture Template

## Prompt to send customers
1. What were you trying to build?
2. What did this starter help you ship faster?
3. What measurable outcome did you get (time saved, features shipped, client delivery speed)?
4. Would you recommend it to other founders/agencies? Why?

## Consent line
"I allow this testimonial to be used in public marketing materials."
