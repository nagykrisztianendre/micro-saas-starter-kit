# Launch Checklist

Use this checklist to ship the starter kit as a paid product with minimal last-minute chaos.

## Product artifact and listing
- [ ] Build release ZIP using the structure in `docs/release-contents.md`
- [ ] Verify ZIP in a clean environment
- [ ] Upload ZIP to Gumroad
- [ ] Finalize Gumroad title, summary, and long description (`docs/sales/gumroad.md`)
- [ ] Configure pricing tiers (Lite/Pro/Team)

## Marketing assets
- [ ] Capture required screenshots (`docs/launch/screenshots.md`)
- [ ] Add screenshots to README and listing pages
- [ ] Publish/update docs landing page (`docs/index.html`)
- [ ] Add Gumroad CTA links in README and docs

## Launch communication
- [ ] Publish announcement posts (X/LinkedIn/Indie Hackers/etc.)
- [ ] Send outreach to warm contacts (`docs/launch/outreach-list-template.csv`)
- [ ] Prepare testimonial request template (`docs/launch/testimonial-template.md`)

## Post-launch operations
- [ ] Collect first buyer feedback
- [ ] Track recurring setup issues and improve docs
- [ ] Record/publish demo video using `docs/demo-script.md`
- [ ] Review support load and update `docs/support.md` response expectations
