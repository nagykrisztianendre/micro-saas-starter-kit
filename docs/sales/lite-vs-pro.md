# Lite vs Pro vs Team

## Lite (public repository)
- Core architecture
- Auth module foundation
- Basic dashboard flows
- Documentation preview

## Pro (paid ZIP)
- Billing/admin module positioning
- Advanced onboarding and troubleshooting docs
- Release templates and launch materials
- Support automation templates

## Team (commercial/team license positioning)
- Everything in Pro
- Team onboarding emphasis for agencies/internal squads
- Priority support placeholder and commercial usage messaging

## Positioning guidance
- Use Lite to build trust and SEO visibility.
- Use Pro to monetize speed and reduced setup friction.
- Use Team to monetize license scope and collaborative enablement.
