# Lite vs Pro vs Team License

Use this page in README, landing pages, and direct buyer conversations.

## Lite (public repository)

Lite is intentionally strong enough for developers to evaluate architecture quality and coding standards before buying.

Includes:
- Core modular architecture
- Authentication foundation
- Dashboard preview experience
- Limited documentation set for evaluation

Best for:
- Technical evaluation
- Learning module boundaries
- Deciding whether Pro saves enough time

## Pro (paid download)

Pro is for teams that want to ship a real product faster with fewer setup unknowns.

Includes:
- All modules included in the commercial package
- Teams and member-invite flows
- API key management patterns
- Email system integration docs
- Audit logs workflow
- Feature flags workflow
- Production-oriented documentation
- Deployment guides
- Advanced implementation docs
- Buyer support documentation

Best for:
- Founder-led SaaS launches
- Agencies shipping client portals
- Teams standardizing on one starter base

## Team License (optional)

Team License is a commercial packaging option for groups using the kit across multiple contributors.

Includes:
- Everything in Pro
- Commercial use language for team usage
- Multi-seat/internal team access terms
- Priority support placeholder (define policy before launch)

## Positioning guidance

- Lead with **Lite** to build trust through code quality.
- Convert with **Pro** by emphasizing time saved and reduced launch risk.
- Upsell **Team License** for agencies and internal product teams that need broader usage rights.
