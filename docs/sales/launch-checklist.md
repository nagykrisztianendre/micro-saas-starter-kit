# Sales Launch Checklist

## Pre-sale checklist
- [ ] Pricing reviewed (Lite/Pro/Team)
- [ ] Gumroad product page draft finalized
- [ ] Product description + bullets finalized
- [ ] ZIP artifact naming follows version convention
- [ ] Support templates and FAQ reviewed

## Launch-day checklist
- [ ] Create version tag and release
- [ ] Confirm release ZIP artifact uploads successfully
- [ ] Upload ZIP to Gumroad
- [ ] Publish landing page updates
- [ ] Publish launch post + outreach messages

## Post-launch checklist
- [ ] Capture first 3 buyer questions for FAQ updates
- [ ] Collect 1–3 testimonials
- [ ] Log objections and adjust pricing/positioning copy
- [ ] Publish patch release if setup friction appears
