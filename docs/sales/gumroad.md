## Long description
Micro-SaaS Starter Kit Pro helps developers launch commercial SaaS products faster with a codebase that is structured for real-world customization.

This is not a one-file template. It is a module-oriented foundation designed for maintainability, testing, and growth. You get architecture, feature scaffolding, and practical documentation for setup, onboarding, packaging, and launch.

If you are building a B2B SaaS, internal portal, agency accelerator, or paid side project, this kit gives you a strong starting point without locking you into black-box abstractions.

## Installation overview
1. Unzip package
2. Install dependencies with `pnpm install`
3. Copy `.env.example` to `.env`
4. Run `pnpm prisma:generate`
5. Run `pnpm prisma:migrate`
6. Seed with `pnpm prisma:seed`
7. Start app with `pnpm dev`
