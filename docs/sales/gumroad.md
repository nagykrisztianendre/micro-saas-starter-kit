# Gumroad Delivery Guide

## Product setup
1. Create product: **Micro-SaaS Starter Kit Pro**.
2. Add thumbnail, short pitch, and key outcomes.
3. Configure checkout fields for buyer email and optional company name.

## Upload steps
1. Create a tagged release in GitHub (e.g., `v1.0.0`).
2. Download release ZIP artifact from GitHub Actions.
3. Upload artifact to Gumroad product files.
4. Add release notes summary in Gumroad update.

## File naming recommendations
- `micro-saas-starter-kit-pro-v1.0.0.zip`
- `micro-saas-starter-kit-team-v1.0.0.zip` (if separate Team delivery)
- Keep semver in file names for support clarity.

## Product description draft
> Launch your SaaS faster with a modular Next.js starter kit packaged for builders and teams. Includes auth, dashboard, billing/admin foundations, deterministic setup, release automation, and practical docs for low-support delivery.

## Summary bullets for sales page
- Modular architecture designed for fast customization
- Auth + dashboard + billing/admin starter flows
- Launch assets, support templates, and release workflow included
- Designed for creator-founders, freelancers, and agencies
